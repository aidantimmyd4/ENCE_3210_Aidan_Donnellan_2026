# Microprocessors - Donnellan - Winter 2026
Final Project Phase 2 folder contains all files associated with the design of the Arduino Nano Every Atmospheric Ballon Shield.
Directory:
  - Components: All custom components made for shield.
  - Docs: Supporting documents showing schematic, PCB layout, footprint layout, and block diagrams.
  - gerber: All gerber files for manufacturing of PCB
  - .kicad_pcb, .kicad_sch, .kicad_pro, .kicad_prl program files
  - fp-info-cache and fp-lib-table
  - Pretty Folders: All custom footprints for board components.
  - Presentation: Design and component evaluation and choices associated with the Atmospheric Balloon Shield
Thank you for viewing!
